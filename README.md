# Lead Miner Pro

Lead Miner extrai dados do Google Maps e da base oficial de CNPJs, pontua oportunidades automaticamente e dispara mensagens personalizadas via WhatsApp — tudo em uma única plataforma.

## Configuração

1. Configure o arquivo .env com as variáveis de ambiente:

VITE_SUPABASE_PROJECT_ID=
VITE_SUPABASE_PUBLISHABLE_KEY=
VITE_SUPABASE_URL=

2. Configure o arquivo config.toml com o project_id do seu projeto Supabase.

## Deploy

Faça deploy usando a aplicação Deploy Manager Pro

## Modo Local

Para rodar o projeto localmente, use o comando:

1. npm install
2. npm run dev
